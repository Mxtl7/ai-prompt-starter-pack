## Why these are "complete" (and free)

Most "free prompt lists" are stubs. These are the actual full systems from the paid pack — given away because the fastest way to show you the quality is to let you run it.

Every prompt ships with three things that separate a $0 result from a usable one:

1. **A system prompt** that locks the AI into a role and a quality bar (no generic assistant voice).
2. **Structured blocks with `[bracket]` slots** so the same prompt adapts to *your* niche in one edit.
3. **`[VERIFY]` / `[CONFIRM]` anti-hallucination flags** so the model flags what it must not invent (statistics, prices, legal/medical claims).

## How to use

1. Open any file in [`prompts/`](prompts/).
2. Copy the code block (the prompt).
3. Replace the `[brackets]` with your service, niche and details.
4. Paste it into ChatGPT, Claude, Gemini, Mistral, or a local model.
5. Run it, then refine once for your voice.

No install. No API key. No account. It's plain `.md` — works anywhere you can paste text.
