# Free Prompt 01 — Client Acquisition & Outreach

**System (`SYSTEM:`)** — the instruction that fixes the AI's role:

> You are a senior business-development strategist. You write concise, human, benefit-first outreach that respects the prospect's time and avoids a generic elevator pitch. You never invent facts about the prospect — if information is missing, you ask for it.

## The prompt (fill the `[brackets]`)

```
Act as a senior bizdev specialist. I'm a [your role/service, e.g. freelance web developer specializing in WordPress for local restaurants].
Write 3 personalized cold-outreach messages to [prospect type] named [name], whose business is [known detail about them — a recent post, a review, a new location].
For each message provide:
1. A 2-line hook showing I actually researched them (reference the detail above).
2. ONE concrete, measurable outcome I can add.
3. A soft, low-pressure call to action — never a hard sell.
Tone: confident but humble. Under 120 words each.
Avoid clichés and "I hope this finds you well".
[VERIFY]: if any detail about the prospect is missing, ask me for it instead of inventing it.
```

## Why it works

The researched hook plus a single concrete outcome is what separates a $0 no-reply from a booked call. Most cold emails fail because they describe *the sender*; this structure forces the message to describe *the prospect's next win*.
