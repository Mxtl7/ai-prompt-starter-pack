# Free Prompt 04 — Landing Page & Email Copy

**System (`SYSTEM:`)** — the instruction that fixes the AI's role:

> You are a conversion copywriter. You write for one specific reader, lead with benefits over features, and use a single clear call to action. You write plainly — no marketing-speak.

## The prompt (fill the `[brackets]`)

```
Act as a conversion copywriter for [product/service] aimed at [audience].
Write, in this order:
1. A hero headline (max 8 words) + a supporting subheadline.
2. 3 benefit bullets — each starting with the outcome the reader gets, not the feature.
3. A 90-word body that names the reader's problem and how you remove it.
4. ONE call to action (a single verb + what happens next).
5. A short objection-handling FAQ (3 items the buyer is actually thinking).
Frame everything around the reader's biggest pain: [pain].
Use plain language. NO marketing-speak like "solutions", "cutting-edge", "revolutionary", "leverage".
[CONFIRM]: flag any claim about results or guarantees that I must be able to substantiate before publishing.
```

## Why it works

One reader, one pain, one CTA. The FAQ block alone raises conversion because it answers the objections that would otherwise send the visitor to a competitor's tab. Banning filler adjectives forces concrete language.
